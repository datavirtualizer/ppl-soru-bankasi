# 501 — Kısa Ezber Listesi (soru kelimesi → cevap)

Ders notu quiz sorularından damıtılmış hızlı tekrar listesi. Uzun anlatım
[501-ders-notlari.md](501-ders-notlari.md) içinde; sınavdan önce sadece bunu oku.

## Hava araçları
- pistonlu itki → **pervane**
- denge → **kuyruk**
- havadan hafif → **balon + zeplin**
- döner kanat taşıma → **rotor**
- CNS bakımı → **ATSEP** (elektronik personel)

## İşletmeler
- bagaj teslim → **check-in** (alınan: koltuk + saat + kapı)
- ruhsatta olmayan → **uçağın değeri** (sigorta bedeli de yok)
- iş modeli sınıflaması → **ürün/hizmet özellikleri**
- tarifeli → **düzenli + herkese açık**

## Havalimanı
- **3 harf = IATA** (IST), **4 harf = ICAO** (LTFM)
- kara tarafı → **check-in salonu**
- hukuk/denetim → **temsil–yönetim–gözetim**
- sınırlı bakımda olmayan → **ikram**
- rampta olmayan → **yolcu kontrolü**

## Bakım
- hangar → **üs** · sefer arası → **hat**
- üste olmayan → **uçuş öncesi bakım**
- düzeltici = **arıza giderme**
- tip sertifikası: **uçak + motor + pervane** ("sadece gövde" yanlış)

## Seyrüsefer
- yer → **meydan** / tırmanış-alçalma → **yaklaşma** / seyir → **saha**
- ATS → **Ek-11**
- akış yönetimi → **4 aşama**
- uçuş bilgi: "herkese ayrımsız" **yanlış** (bilinen uçaklara verilir)
- uyarı hizmeti → **SAR'ı uyarmak**

## Kuruluşlar
- AB emniyet → **EASA**
- Varşova → **"Bazı Kuralların Birleştirilmesi"**
- ICAO amacı olmayan → **Avrupa Komisyonuna danışmanlık** ¹
- Şikago eki olmayan → **havacılık eğitimi**
- ECAC → **Avrupa taşımacılığını teşvik**

## Çevre
- gelecek nesil tanımı → **sürdürülebilirlik**
- CORSIA → **Karbon Denkleştirme**
- tanımla–değerlendir–izle–azalt → **ÇYS**
- **Cilt III → CO₂** (Cilt IV → CORSIA)
- Devlet Eylem Planı'nda olmayan → **yurt dışı paydaşlar**

---
¹ Aynı soru ATPL TV bankasında farklı şıklarla gelir; orada cevap **"sadece askerî
havacılığı geliştirmek"**tir. İkisi de ICAO'nun amacı değildir — şıklara göre seç.
(Avrupa Komisyonuna danışmanlık **EASA'nın** görevidir.)
